# HYBRID-FRAUD-DETECTION-ML
The proposed **FraudFusion++** algorithm detects fraudulent UPI transactions using a hybrid approach. First, the transaction dataset is preprocessed by converting text values into numbers and extracting useful features such as the transaction hour. Next, **Isolation Forest** identifies unusual or suspicious transactions and generates an anomaly score. This score is combined with the original transaction details and given to the **CatBoost** classifier, which learns fraud patterns from historical data and predicts the probability of fraud. Finally, the proposed **Adaptive Risk Decision Engine (ARDE)** analyzes the fraud probability along with the anomaly score, transaction amount, and transaction time to assign a risk level (Low, Medium, or High) and make the final decision of whether the transaction is **Fraud** ,**Review** or **Genuine**.
